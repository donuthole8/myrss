# Coffeed

珈琲を飲んでいるあいだに情報収集を済ませるための RSS / Atom リーダー。3ペイン構成で、購読状態はブラウザの localStorage に持つ。

```bash
npm run dev   # http://localhost:3000
```

## できること

- **購読** — サイトのURLを入れるとフィードを自動探索（`<link rel="alternate">` → `/feed` `/rss.xml` などの定番パス）。フォルダ分け可。
- **RSS の無いサービスも購読** — YouTube（チャンネル・@ハンドル・再生リスト）、GitHub（リリース・タグ・コミット・ユーザーの活動）、Reddit、Bluesky、Mastodon、note、Zenn、Qiita（ユーザー・タグ・Organization）、Medium、dev.to、Speaker Deck は、ページの URL を貼るとフィードの URL に置き換えて購読する。変換ルールは `src/lib/sources.ts`。
- **3ペイン** — サイドバー（フォルダ / フィード・未読数）、記事一覧、本文ビュー。
- **未読管理** — 開いた記事を自動で既読に。未読のみ表示、表示中を一括既読。
- **スター** — 記事本体ごと保存するので、フィードから流れ落ちても残る。
- **検索** — タイトル / 要約 / フィード名を横断。
- **OPML** — 読み込みと書き出し。他のリーダーからの移行・退避用。
- **テーマ** — system / light / dark を切り替え。初回描画前に当てるのでちらつかない。
- **おすすめフィード** — サイドバーの「おすすめから探す」（または「フィードを追加」内のカード）で、12カテゴリ・約100件のフィード一覧を開く。国内トレンド（Qiita 人気記事・Zenn・はてブ）、AI、国内 IT ニュース、海外テック、週刊まとめ、設計・エンジニアリング、Web、クラウド、セキュリティ、企業テックブログ、海外テックブログ、言語。各フィードの説明と最新記事を見て、ワンクリックで追加・解除できる。カテゴリごとの一括追加もあり、カテゴリ名のフォルダに入る。一覧は `src/lib/presets.ts`。
- **AI ニュース** — 購読中の全フィードから AI 関連の記事だけを集める横断ビュー。「AI」フォルダのフィードは丸ごと、それ以外はタイトル・要約のキーワード（`src/lib/topics.ts`）で拾う。
- **タイトルの日本語訳** — 英語などのタイトルを DeepL API Free で訳して表示。訳には「訳」バッジを付け、原文を下に出す。記事ビューではバッジを押すと見出しを原文に切り替えられる。訳は原文をキーにブラウザへ貯めて、同じタイトルは二度訳さない。
- **OGP で補完** — フィードに画像が無い記事（Qiita / Publickey / HN など）や、要約が中身を表していない記事（HN の「Article URL: …」など）は、表示したときに元記事の og:image / og:description を取って補う。結果はブラウザに貯め、サーバー側も Data Cache に1日載せる。OpenAI のようにボット対策で弾くサイトは取れない。
- **好みの学習（おすすめ順）** — 開いた・スターを付けた記事を「気になる」、「興味なし」(`D`) と開かずに一括既読した記事を「興味なし」として、ブラウザ内のナイーブベイズで学習する。単語分割は `Intl.Segmenter`。学習が溜まると、おすすめ順では好みでない記事を隠す。外部には何も送らない。
- **キーワード** — 興味ワード（おすすめ順で上げる）とミュートワード（タイトルに含む記事を隠す）。英語記事は訳したタイトルでも照合する。
- **話題** — 同じ記事・よく似たタイトルの記事が HN・はてブ・Zenn など複数のフィードに出ていたら1件に束ね、「何ソースで話題か」「はてブ数」「HN ポイント」で順位を付ける横断ランキング。どのビューでも「話題順」で並べ替えられる。はてブ数は購読元に関係なくすべての記事に付く（`/api/buzz`）。
- **関連記事** — 本文の下に、タイトル（訳を含む）と要約の語が近い記事を最大5件出す。購読中の記事とスターが対象で、同じ話題として束ねた記事は除く。語の重みは TF-IDF で、どこにでも出る語や HN の定型文は効かせない（`src/lib/related.ts`）。
- **重複の既読共有** — 束ねた記事はどれか1つを読めば全部既読になる。同じニュースを何度も見ない。
- **急上昇キーワード** — 記事タイトルの語を公開日ごとにブラウザへ貯め、直近2日の出現数がその前の1週間より跳ねた語をチップで出す（「すべての記事」「話題」）。押すとその語で絞り込む。使い始めは履歴が薄いので、数日使うほど精度が上がる。
- **ウォッチ** — キーワードを登録すると、全フィードからタイトル・要約で拾って1か所にまとめる。Google ニュースの検索結果 RSS も一緒に購読できるので、購読していないサイトの記事も入ってくる。
- **フィードの編集** — フィード・フォルダを右クリック（スマホは長押し）、または鉛筆ボタンで、表示名の変更・フォルダ移動・フォルダ名の変更と統合・購読解除。自分で付けた名前は更新で上書きされない。
- **スマホ操作** — 一覧を下に引っ張って更新、記事を右スワイプでスター・左スワイプで既読 / 未読、本文を右に払うと一覧へ戻り左に払うと次の記事。端末の「戻る」でも一覧に戻る。
- **ショートカット** — `J`/`K` 移動、`O` 元記事、`M` 既読切替、`S` スター、`D` 興味なし、`P` 新着 → おすすめ → 話題順、`U` 未読のみ、`R` 更新、`A` 追加、`/` 検索、`?` ヘルプ。

## 構成

| パス | 役割 |
| --- | --- |
| `src/app/api/feed/` | フィード取得。`GET` は単体（購読前プレビュー）、`POST` は購読中を一括更新。5分のメモリキャッシュ付き |
| `src/app/api/discover/` | サイトURLからフィードを探す。同じ中身を返す別URLは1つに畳む |
| `src/app/api/icon/` | ファビコンのプロキシ。外部サービスに購読リストを渡さずに済ませるため |
| `src/app/api/ogp/` | 元記事ページの og:image / og:description。1回40件まで、8並列 |
| `src/lib/ogp.ts` | OGP が要る記事の判定と、結果のキャッシュ（localStorage `feedly-clone:ogp:v1`） |
| `src/app/api/translate/` | DeepL でタイトルを訳す。同一オリジンからの呼び出しだけ受け、1回50件まで |
| `src/lib/presets.ts` | おすすめフィードのカタログ。載せる前にこのアプリで読めて更新が続いていることを確かめる |
| `src/lib/prefer.ts` | 好みの学習（単語分割・ナイーブベイズ・キーワード照合）。学習結果は localStorage `feedly-clone:model:v1` |
| `src/lib/translate.ts` | 翻訳対象の判定と訳のキャッシュ（localStorage `feedly-clone:translations:v1`） |
| `src/app/api/buzz/` | 記事URLごとのはてなブックマーク数（はてなの公開 API を30件ずつ中継） |
| `src/lib/stories.ts` | 記事をストーリーに束ねる（URL正規化 + タイトルの類似度）と話題度 |
| `src/lib/sources.ts` | YouTube・GitHub などのページ URL をフィード URL に置き換える規則（`/api/discover` が使う） |
| `src/lib/related.ts` | 関連記事（TF-IDF のコサイン類似度） |
| `src/lib/trends.ts` | 急上昇キーワード。日ごとの語の出現数は localStorage `feedly-clone:trends:v1` |
| `src/lib/gestures.ts` | スワイプ・引っ張って更新・長押しのフック |
| `src/lib/rss.ts` | RSS 2.0 / Atom / RDF(RSS 1.0) のパースと本文のサニタイズ |
| `src/lib/net.ts` | URL検証・タイムアウト・文字コード判定・TTLキャッシュ |
| `src/lib/store.ts` | localStorage の読み書き（キー: `feedly-clone:v1`） |
| `src/components/Reader.tsx` | 状態の持ち主。他のコンポーネントはすべて props 受け取り |

フィードの取得とパースはすべてサーバー側（Route Handler）でやる。ブラウザから直接叩くと CORS で弾かれるのと、本文のサニタイズをクライアントに任せたくないため。

## 制約・メモ

- 購読データは**そのブラウザの localStorage にしかない**。別デバイスと同期はしない（OPML書き出しで移す）。
- 記事キャッシュはサーバーのメモリなので、プロセスを再起動すると消える（次のアクセスで取り直す）。
- 取得先URLはループバック / プライベートIP帯を弾いている。ただしリダイレクト先までは追跡していない。
- 本文は `sanitize-html` を通し、iframe は YouTube / Vimeo / SoundCloud / Speaker Deck のみ許可。

## デプロイ（Vercel）

```bash
npx vercel          # 初回: プレビュー環境に上げてリンク作成
npx vercel --prod   # 本番へ
```

Hobbyプランの上限は**200プロジェクト / 100デプロイ per day**なので、プロジェクト数は気にしなくてよい。

### 環境変数

| 名前 | 必須 | 内容 |
| --- | --- | --- |
| `DEEPL_API_KEY` | 任意 | タイトル翻訳用。未設定なら翻訳だけ止まり、他は普通に動く |

DeepL API Free（月50万文字まで無料）のキーは https://www.deepl.com/pro-api で登録して取得する（末尾が `:fx`）。

```bash
npx vercel env add DEEPL_API_KEY production   # 値を貼り付け
npx vercel --prod                             # 環境変数は再デプロイで反映される
```

ローカルでは `.env.local` に `DEEPL_API_KEY=...` を書く。

### スマホで使う

本番URLをスマホのブラウザで開いて「ホーム画面に追加」すると、スタンドアロン表示（アドレスバーなし）のアプリとして起動する。`src/app/manifest.ts` と `public/icon-*.png` がその定義。

**注意: 購読データは端末ごとに別**。localStorageにしか持っていないので、PCとスマホは同期しない。移すときはPC側でOPMLを書き出し → スマホ側で読み込む。既読・スターは移らない。

### サーバーレスでの挙動

- フィード取得は Next の Data Cache（`revalidate: 300`）に載せている。インスタンスが使い捨てられてもキャッシュは効く。`src/lib/net.ts` の `fetchWithLimit` が窓口。
- `TtlCache`（メモリ）は同一インスタンスに連続で当たったときのパース結果の使い回し用。サーバーレスでは当たったらラッキー程度のもの。
- 関数の実行時間上限は各 route の `maxDuration` で指定（feed 30s / discover 45s / icon 20s）。個別のfetchは10秒でタイムアウトさせている。

### 公開範囲

URLを知っていれば誰でも開けるし、`/api/feed` は任意のURLを取りに行くプロキシとして使える。気になるなら Vercel の Project Settings → Deployment Protection → Vercel Authentication を有効にする（自分のVercelアカウントでログインした人だけがアクセスできる）。
